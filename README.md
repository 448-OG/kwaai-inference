## Kwaai Inference

This is a fork of [kwaai-inference](https://github.com/Kwaai-AI-Lab/KwaaiNet/tree/main/core/crates/kwaai-inference) crate that is part of [Kwaai-Net](https://github.com/kwaai-ai-lab/kwaainet).

It adds support for Qwen3 AI and has been tested locally with `Qwen3-4B-Q8_0`. The crate has been removed from the Kwaai-Net repository due to codespace configuration interfering with rust-analyzer and taking too much time away from development to solve those issues.

The license remains MIT even with the modifications.
